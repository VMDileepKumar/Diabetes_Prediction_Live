# Diabetes Prediction

A small educational diabetes classification project using the supplied dataset, a scaled linear SVM, and a Streamlit interface.

## Project structure

```text
data/diabetes.csv
notebooks/diabetes_analysis.ipynb
src/preprocessing.py
src/train.py
src/predict.py
models/diabetes_model.pkl  # generated by training
app.py
requirements.txt
```

## Setup and run

Run these commands from the project root:

```powershell
python -m pip install -r requirements.txt
python -m src.train
python -m streamlit run app.py
```

The training command evaluates the model on a stratified test split and saves the fitted preprocessing and classifier pipeline to `models/diabetes_model.pkl`. The app requires that training step to have completed.

The notebook is for exploratory analysis; the training script is the source of the saved model used by the app.

This project is for educational use only. Its predictions are not medical advice or a diagnosis.
